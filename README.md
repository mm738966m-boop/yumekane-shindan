## 📦 STEP 1：Netlifyにウェブ診断を公開

### 1-1. Netlifyにアカウント作成

https://www.netlify.com/ にアクセス

「Sign up」をクリック → **GitHubまたはGoogle**でサインアップ（無料）

### 1-2. サイトをアップロード

1. Netlifyにログイン
2. 上部メニューから「**Sites**」をクリック
3. ページ下部の点線で囲まれた領域に注目

```
┌─────────────────────────────────┐
│  Drag and drop your site         │
│  output folder here              │
│  （ここにフォルダをドラッグ&ドロップ）  │
└─────────────────────────────────┘
```

4. **`yumekane_final` フォルダごと**、この領域にドラッグ&ドロップ
5. 自動でデプロイ開始（約30秒）
6. デプロイ完了 → URLが発行される（例：`https://random-name-12345.netlify.app`）

### 1-3. サイト名をカスタマイズ（推奨）

1. 「**Site overview**」画面で、「**Site settings**」をクリック
2. 「**Site details**」→「**Change site name**」をクリック
3. 名前を入力：例 `yumekane-shindan`
4. URLが `https://yumekane-shindan.netlify.app` に変わる

✅ **STEP 1完了！**

## 🔗 STEP 2：公開URLを取得

Netlifyの「**Site overview**」画面の上部に表示されているURLをコピー。

例：`https://yumekane-shindan.netlify.app`

このURLは次のステップで使うので、メモしておいてください。

## ⚙️ STEP 3：公開URLをコードに反映

ウェブ診断のシェアボタンが正しく動くように、コードを更新します。

### 3-1. script.jsを編集

**お手元のPC**で、`script.js` をテキストエディタ（メモ帳でもOK）で開く。

### 3-2. 12行目を編集

以下の行を探す：

```javascript
SITE_URL: 'https://yumekane-shindan.netlify.app',
```

ここを、**STEP 2で取得した実際のURL**に書き換える。

書き換え例：

```javascript
SITE_URL: 'https://yumekane-shindan.netlify.app',  // ← Netlifyで取得したURLに書き換え
```

### 3-3. Netlifyに再アップロード

1. Netlify管理画面の「**Deploys**」タブを開く
2. ページ下部の「**Drag and drop**」エリアに、**更新したyumekane_finalフォルダ**を再度ドラッグ&ドロップ
3. 上書き完了

✅ **STEP 3完了！**

## 💬 STEP 4：LINE管理画面で挨拶メッセージを設定

ここが少し複雑なので、丁寧に説明します。

### 4-1. LINE Official Account Managerにログイン

1. https://manager.line.biz/ にアクセス
2. 「ユメカネお金の診断室」のアカウントにログイン

### 4-2. あいさつメッセージ設定画面を開く

1. 左メニューの「**ホーム**」をクリック
2. 上部メニューの「**メッセージ配信**」または「**あいさつメッセージ**」をクリック

または：

1. 左メニュー「**ホーム**」→「**応答メッセージ**」→「**あいさつメッセージ**」

### 4-3. デフォルトメッセージを削除

既存のデフォルトメッセージ（「友だち追加ありがとうございます」など）があれば、削除またはオフにする。

### 4-4. 新規メッセージを追加

「**+ 追加**」または「**メッセージを作成**」ボタンをクリック。

### 4-5. メッセージタイプを「画像」に設定

メッセージのタイプを選択：

- **画像** を選択（リッチメッセージではなく、通常の「画像」でOK）

### 4-6. 画像をアップロード

「**画像を選択**」または「**アップロード**」ボタンをクリック。

同梱の `LINE_greeting_image.png` をアップロード。

### 4-7. 画像にリンクを設定（重要）

画像をアップロードした後：

1. 画像の下部または編集画面に「**リンクURL**」または「**アクションURL**」設定欄がある
2. ここに以下を入力：

```
https://[あなたのNetlify URL]/?from=line
```

例：
```
https://yumekane-shindan.netlify.app/?from=line
```

⚠️ **重要**：URLの最後に `/?from=line` を必ず付けてください。
これを付けないと、LINEから戻ってきた時に結果ページに遷移しません。

### 4-8. 保存・有効化

1. 「**保存**」ボタンをクリック
2. あいさつメッセージを「**有効**」に切り替える

### 4-9. テスト

別のスマホで、LINEの友だち追加URL `https://lin.ee/Tpi8Xg3` を開いて、登録してみる。

期待される動作：
1. 友だち追加直後に画像メッセージが届く
2. 画像をタップすると、ウェブ診断の結果ページに遷移
3. 直前に受けた診断結果が表示される

✅ **STEP 4完了！**

## 🛠 トラブルシューティング

### Q1：診断結果が表示されない

**原因**：localStorageが無効になっているか、ブラウザを完全に閉じてしまった
**対策**：「もう一度診断する」ボタンから再受診を案内

### Q2：シェアボタンが動かない

**原因**：script.jsのSITE_URLが正しく設定されていない
**対策**：STEP 3を再実行

### Q3：LINE経由で戻った時、結果が表示されない

**原因**：LINEメッセージのリンクURLに `/?from=line` が付いていない
**対策**：STEP 4-7を再確認

### Q4：Netlifyのデプロイが失敗する

**原因**：フォルダ構造が崩れている
**対策**：yumekane_finalフォルダごとアップロードし直す
